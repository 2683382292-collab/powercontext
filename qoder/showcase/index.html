个性化复习助手
一个越用越懂你的复习教练

复习时找不到上学期的错题、刷题不分掌握与否、每次复习都从零开始？本项目用 PowerContext 记住每位学习者的薄弱知识点、错题与复习进度，新开对话自动回忆历史并针对性出题复盘。

FastAPI 后端原生网页前端无模型即可运行 每学习者记忆隔离后端无状态可随时重启
代码仓库 运行说明 验证样例

01解决的问题

从自己真实的复习痛点出发：错过的题还会再错，因为"薄弱点"从来没有被系统地记住。

薄弱点记不住

错题和易错知识点散落在笔记、试卷和聊天记录里，考前想复盘却找不全、理不清。

出题没有针对性

刷题不区分已掌握和未掌握的内容，会做的反复做、不会的总漏掉，复习效率低。

进度不留痕

每次复习都从零开始，没有纵向对比，看不到自己哪些知识点在进步、哪些仍在退步。

02核心功能

三大功能闭环：作答即记录、开新对话即回忆、网页即交互入口。

功能 1 · 记忆记录

薄弱点 / 错题 / 进度持久化

每次作答自动判分：答错追加一条错题事件；无论对错都刷新该知识点的薄弱点快照（尝试次数、错误次数）与本轮复习进度，全部写入 PowerContext 长期保存。

功能 2 · 记忆复用

新开对话自动回忆 + 针对性出题

开启新一轮复习时先读取历史记忆：优先重练最近错题，再靶向错误次数最多的知识点，最后用诊断题补齐；没有任何历史时自动出诊断题摸清基础。

功能 3 · 网页交互

单页网页前端

浏览器内完成开始复习、作答与解析查看、薄弱知识点列表、错题本、复习进度总览；顶部实时显示 PowerContext 连接状态。

03PowerContext 在项目中的实际作用

PowerContext 作为记忆与上下文引擎：记忆被保存，并在后续每一次"新对话"中被真实复用——不是仅安装或测试连接。

记忆 kind写入时机主要内容复用方式
wrong_question答错时追加一条题目、选项、正确/所选项、时间新会话优先重练最近错题；错题本展示
weak_point每次作答刷新快照学科、知识点、尝试/错误次数按错误次数排序靶向出题；总览排序
review_progress每次作答刷新快照会话、题数、正确数、薄弱点列表复习进度总览与正确率统计

读写全部通过 PowerContext HTTP API 完成：POST /v1/scopes（每学习者一个隔离 Scope）、 POST /v1/memory/remember（写记忆）、POST /v1/memory/entries/list（读历史）、 POST /v1/context/prepare（生成叙述式回忆展示给学习者）、GET /health/live（连接探针）。

# 记忆闭环示意：答错 → 写入 → 新对话读回 → 靶向出题
作答 POST /api/answer  ──►  /v1/memory/remember   写入 wrong_question + weak_point + review_progress
新会话 POST /api/session/start  ──►  /v1/memory/entries/list  读回历史
        └─► 错题重练 → 靶向薄弱点 → 诊断补齐；并调用 /v1/context/prepare 生成"助手回忆"

05运行说明

环境：Python 3.11+；依赖见 qoder/requirements.txt（fastapi、uvicorn、httpx、pydantic；测试用 pytest）。PowerContext 默认 Basic memory 模式，无需任何模型 API Key。

# 终端 1：启动 PowerContext Server（仓库根目录，默认 127.0.0.1:8000）
uv sync --extra cli --extra server
uv run powercontext server run

# 终端 2：启动复习助手（qoder 目录，默认 127.0.0.1:8080）
cd qoder
uv run python run.py          # 或：python -m pip install -r requirements.txt; python run.py

# 浏览器打开体验入口
# http://127.0.0.1:8080/

06验证样例

三组可复现样例，覆盖离线测试、端到端冒烟与手动体验，均能观察到 PowerContext 记忆读写记录。

  1. 离线自动化测试（无需真实 Server）在 qoder 目录执行 python -m pytest -q，使用内存版假 PowerContext 跑通"写记忆 → 读历史 → 靶向出题"闭环。预期：9 passed。
  2. 端到端冒烟测试（两个服务运行中）执行 python scripts/smoke_test.py，依次验证存活探针、首次诊断出题、答错写入记忆、总览读回、新会话靶向薄弱点。预期：每步 [PASS]，退出码 0。
  3. 网页手动验证打开首页 → 故意答错几题 → 查看学习总览 → 再开新一轮复习。预期：总览读回薄弱点/错题/进度；新会话出现"已载入历史记忆"提示与靶向题标签。
